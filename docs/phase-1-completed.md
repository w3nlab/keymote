# Keymote 一期已完成能力

一期已完成 Keymote 的 macOS 本地遥控器映射基础、应用 Profile、语音转写和配置诊断能力。

## Siri Remote 支持

- 支持第三代 Apple Siri Remote（A2854）已验证的 HID 按键输入。
- 支持方向键、中央键、返回、TV、播放/暂停、静音、音量加减和 Siri 键。
- 提供输入诊断模式和触控板原始 HID 报告采集，便于校验设备事件。
- 通过 Input Monitoring 接收 HID 输入，通过 Accessibility 向前台应用注入键盘操作。

## 按键映射与手势

- 每个按键支持单击、双击和长按三种手势。
- 双击间隔可配置，默认 300ms；长按阈值可独立配置。
- 所有 Profile 的双击默认均为 `No Action`。
- 支持方向、回车、Escape、Delete、播放/暂停、静音、音量、切换应用、退出应用切换器、启动选定应用等预定义 Action。
- TV 键可启动用户选择的 macOS 应用；长按 TV 可进入应用切换器，并用方向/中央/返回键完成选择、确认和取消。
- 支持交互式遥控器布局编辑器与表单列表编辑器；遥控器布局会随主窗口宽度缩放。

## 内置 Profile

- 内置 Default、Terminal、Ghostty、Otty、Kitty、Chrome、Edge 和 ChatGPT Profile。
- 根据前台应用的 bundle identifier 自动切换 Profile。
- 非默认 Profile 可以将某一按键手势设为“Default”，以继承 Default Profile 的对应动作。
- 支持终端/浏览器 Profile 的标签页切换映射，并保持不适用 Profile 的安全默认值。

## Siri 键语音转写

- Siri 键轻按可启动/停止使用 Mac 麦克风的语音录制；遥控器麦克风路径保留为未实现的实验性选项。
- 转写来源可选 macOS 本地 Speech 或云端转写。
- 本地 Speech 可选择跟随 macOS、英文（美国）或中文（简体，中国大陆）。
- 支持“录音结束后转写”和“实时转写”模式。
- 实时模式会把本地 Speech 的部分结果写入当前光标位置；暂停后识别的新语句以空格续接，并只修正正在识别的尾段。
- 结束录音后会用最终转写结果校正内容；没有辅助功能权限时仅复制到剪贴板。
- 云端转写当前在停止录音后上传音频并返回最终文本，不提供流式实时转写。

## 云端模型配置

- 已提供 Claude、OpenAI 和 OpenRouter 的统一模型配置入口。
- OpenAI 与 OpenRouter 可作为云端转写提供者；Claude 一期仅用于文本生成预留能力。
- API Key 使用每台安装独立的 Keychain 密钥进行 AES-GCM 加密后保存在本地配置中。
- 提供连接测试、模型名称配置以及诊断日志，便于定位权限、语言资产和转写失败原因。

## 应用体验与运维

- 提供中文与英文界面、浅色/深色/跟随系统外观、Dock 显示开关。
- 主窗口默认尺寸为 972 × 760，最小尺寸为 900 × 640。
- 诊断页可查看并复制 HID、语音权限、录音、Speech 回调、云端提交和文本注入日志。
- 本地构建脚本会使用稳定的本地开发签名，帮助 macOS 隐私授权在重建后保持可用。

## 一期边界

- 用户自定义 Profile、用户自定义快捷键 Action 与自动更新机制列入二期。
- macOS 本地 Speech 依赖系统启用 Siri/Dictation，并安装相应语言的语音识别资产。
- 语义级自动补标点未在一期启用，以避免实时转写中错误断句。
